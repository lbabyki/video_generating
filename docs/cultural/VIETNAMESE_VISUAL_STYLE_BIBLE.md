# Vietnamese Visual Style Bible v1.0

Target: educational 2D animation for Grade 4. Use clear silhouettes, warm restrained colors, readable object scale, and age-appropriate daily life. Name the Vietnamese regional setting before selecting references. Do not blend foreign architecture, dress, landscape, or ritual props into a generic “Asian” atmosphere. Diffusion is only for imagery; all Vietnamese text is verified vector/subtitle typography. Cultural approval is a required workflow control, not a guarantee of absolute cultural correctness.
