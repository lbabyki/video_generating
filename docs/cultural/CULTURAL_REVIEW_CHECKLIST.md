# Cultural Review Checklist

- [ ] Region, season, setting, and learning objective are explicit.
- [ ] Geography, architecture, clothing, tools, plants, and activities match the setting.
- [ ] No unverified map, flag, emblem, or political/religious symbol is shown.
- [ ] No foreign cultural or architectural motif is blended into the Vietnamese scene.
- [ ] No unnecessary áo dài/nón lá stereotype is used.
- [ ] All on-screen Vietnamese text is typeset outside diffusion.
- [ ] References have provenance and required usage rights.
- [ ] Child imagery is fictional/illustrated or has appropriate documented permission.
